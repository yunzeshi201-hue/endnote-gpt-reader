# 未完成项与修改办法

每次报告先说明在哪一步停止、哪些结果已真实验证。保留源文章、原始引文台账、已下载文件及其哈希、导入前后快照、RIS 与附件计划。修复只续跑缺失项，不从零重复入库。

## 修复报告至少包含

| 字段 | 内容 |
| --- | --- |
| 目标 | 引文 ID、原始引文、已确认的题名/DOI；或当前软件步骤 |
| 实际状态 | 已提取/待核验/已下载/记录存在/附件缺失/尚未验证 |
| 原因与证据 | 观察到的 HTTP 错误、页面、路径、UI 状态或匹配冲突；不把推测写成根因 |
| 已保留结果 | PDF、候选元数据、RIS、附件计划、ledger 等真实文件链接 |
| 修改办法 | 明确要改的字段、目录、导入选项或脚本逻辑，以及可执行步骤 |
| 恢复入口 | 要继续的 ID/命令和下一次验证方法 |

## 常见阻碍

| 阻碍 | 具体处理 |
| --- | --- |
| 未收到文章或只给了摘要 | 需要原文 PDF、完整参考文献列表或可访问的文章链接；不要猜条目。 |
| 双栏/扫描页导致漏条、并条 | 渲染相关页，核对编号与跨页，必要时 OCR；修订 raw_citation 与 source_pages，再更新 complete 状态。 |
| 书目匹配不唯一 | 对照作者、年份、卷页和版本，给简短候选差异；无法判定的保持 ambiguous，不导入猜测项。 |
| DOI 错或解析不到 | 保留原始文本，按题名和作者查出版社/登记源；确认后修改 DOI，记录证据，不能只删 DOI 后假装匹配。 |
| 无 DOI 的书、标准、软件 | 用官方目录/ISBN/版本信息验证，作为真实对应文献类型记录，不强制伪造期刊字段。 |
| 付费或登录限制 | 尝试合法开放版本、机构仓储或用户正常授权；仍不可得则记录元数据已就绪、全文未取得，以及可用来源链接。 |
| 下载得到 HTML 或错误论文 | 不标下载完成；换成真实 PDF 地址，核对首页身份；保留错误原因，不把 .html 改名 .pdf。 |
| 网络超时、429、证书错误 | 按服务要求等待或切换正式来源；不关 TLS 验证；有限重试后保留候选和继续清单。 |
| EndNote 未安装或无法启动 | 给出官方安装入口/许可证需求，由用户完成安装或登录；RIS 和 PDF 包仍可交付，状态为未导入。 |
| 电脑控制工具不可用或被中止 | 停止相应 UI 输入，不绕过控制限制；提供 File > Import 与 Attach File 的精确接续步骤和文件路径。 |
| 目标库同名或不明确 | 核对 Library Status 中完整 Location；无法唯一确定时等待用户选择，不能把 RIS 双击导入任意当前库。 |
| RIS 导入空白/乱码 | 确认 Reference Manager (RIS) 过滤器和 UTF-8 选项；在新批次测试 1 条再继续，不修改原始引文来迎合错误过滤器。 |
| 已有同 DOI 或重复记录 | 复用已确认条目，缺 PDF 时只附附件；重复条目保持并报告，未经用户要求不自动删除或合并。 |
| 文献记录已导入、PDF 没跟上 | 用附件计划精确选记录，References > File Attachments > Attach File，勾选复制并创建相对链接；导出 after XML 并核对哈希。 |
| PDF 还在临时目录外链 | 对正确记录用受支持的附文件/相对链接转换操作；转换前备份；核实目标 `.Data\PDF` 和打开结果，不能只移动临时文件。 |
| 复制后哈希不同或版本不符 | 检查选错附件、补充材料或版本替换；保留原下载与现有库文件，重新确认对应关系后修复，不直接覆盖 DATA 内部文件。 |
| 条目总数对不上 | 逐条对照 raw ID→唯一论文→目标记录号，区分去重、已存在、未核验和导入失败；不能靠总记录数增加就判断全部完成。 |
| after XML 旧或导错库 | 重新确认库 Location 和导出时间，导出全目标范围，再运行 verify；旧快照不能证明刚刚的操作结果。 |

## 如果是本 skill 的问题

保留失败输入的最小可复现样本，个人文章或文献库不进入通用技能包。指出出错脚本/函数与现象，在任务工作副本修正；运行能复现该故障的测试和受影响的回归测试，再生成更新包或具体补丁。报告改了什么、为什么、如何验证和仍受哪些外部条件限制。

若只是缺文章、缺访问、缺软件或无法操作 UI，说明所需外部输入/动作，不把它包装成脚本缺陷，也不宣称改几行就能保证下载全部付费论文。安装后的通用 skill 仍留在正常 skills 目录，用户论文和操作证据留在外部任务目录。
